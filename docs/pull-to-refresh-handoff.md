# Pull to Refresh Container 전달 명세

## 전달 파일

- `pull-to-refresh-container-export.html`: CSS와 스크립트를 포함한 독립 실행 미리보기. 파일 하나만 복사해 브라우저에서 열 수 있다.
- 원본 미리보기: `preview/pull-to-refresh-container.html`. 이 파일은 현재 디자인 시스템의 `colors_and_type.css`를 참조한다.

HTML은 모바일 상호작용 시안이다. 목록 데이터와 로딩 시간은 미리보기용이며 실제 네트워크 요청이나 Compose 구현은 포함하지 않는다.

## 구현 목표

Ien 디자인 시스템의 모바일 목록에서 당김 갱신과 외부에서 시작된 목록 로딩을 같은 화면 구조 안에 표현한다. 기존 반투명 하단 탭바를 유지하고, 목록의 마지막 행이 탭바에 가려지지 않도록 한다.

## 상태와 화면 표현

| 상태 | 목록 | 상단 인디케이터 |
| --- | --- | --- |
| 대기 | 실제 항목 표시 | 숨김. 상시 안내 문구 없음 |
| 첫 로딩 또는 탭 전환 로딩 | 목록 행 형태의 스켈레톤 표시 | 숨김 |
| 당기는 중 | 기존 목록이 당긴 거리만큼 내려감 | 중앙의 점 세 개가 한 점에서 좌우로 펼쳐짐 |
| 갱신 가능 거리 도달 | 기존 목록 유지 | 약한 브랜드 배경으로 준비 상태 표시 |
| 새로고침 중 | 기존 항목 유지, 목록 시작 위치를 56px 내림 | 점 세 개가 순서대로 위로 흐름 |

로딩 완료 뒤에는 인디케이터가 사라지고 목록이 제자리로 돌아간다. 실패·빈 목록 상태는 이 시안에 포함하지 않았다.

## 크기와 모션

- 목록 좌우 여백 16px, 행 최소 높이 76px, 선행 영역 44×44px.
- 당김 표시 거리: `min(96px, max(0px, 손가락 이동 거리 × 0.65))`.
- 갱신 기준 거리: 표시 거리 56px. 기준에 못 미치면 손을 놓았을 때 원위치로 돌아간다.
- 인디케이터: 높이 36px, 너비 36→72px. 양쪽 점은 중심에서 최대 13px까지 펼쳐진다.
- 갱신 모션: 세 점이 0.9초 주기로 움직이며 시작 시각을 각각 0.15초씩 어긋나게 한다.
- 스켈레톤: 각 행의 44px 선행 형태와 두 줄 텍스트 형태를 1.1초 주기로 약하게 밝기 변경.
- 하단 탭바: 반투명 표면과 흐림 효과, 높이 66px 이상. 목록 하단에 `106px + 안전 영역` 여백 확보.
- 동작 줄이기 설정에서는 반복·이동 애니메이션을 최소화한다.

## Ien 색상 역할

| 용도 | 토큰 | 현재 라이트 값 |
| --- | --- | --- |
| 화면·탭바 표면 | `background`, `surface` | `#FFFFFF` |
| 약한 구획·스켈레톤 | `surfaceWeak`, `surfaceVariant` | `#F9FAFB`, `#F2F4F6` |
| 제목·본문 | `textPrimary`, `textSecondary` | `#191F28`, `#4E5968` |
| 구분선 | `border` | `#E5E8EB` |
| 갱신 점·선택 상태 | `brand`, `brandWeak` | `#3182F6`, `#E8F3FF` |

실제 프로젝트에 이미 Ien 토큰이 있으면 그 토큰을 사용한다. HTML의 색상값을 별도 팔레트로 복제하지 않는다.

## Compose 연결 기준

- `PullToRefreshBox`가 `LazyColumn`을 감싼다. `isRefreshing`은 화면의 실제 갱신 상태와 연결하고, `onRefresh`는 데이터 갱신 요청을 시작한다.
- `rememberPullToRefreshState()`의 `distanceFraction`으로 점의 펼침 정도와 갱신 준비 상태를 구동한다. `indicator` 슬롯에 세 점 인디케이터를 배치한다.
- 첫 로딩은 갱신과 구분한다. 첫 로딩에는 실제 행 대신 스켈레톤을 보여 주고, 이미 표시된 목록의 갱신에는 기존 항목을 유지한다.
- `isRefreshing`은 당김 없이 ViewModel 등의 상태 변경으로 `true`가 되어도 인디케이터를 표시해야 한다.
- HTML의 1.1초·1.2초 타이머는 시연용이다. 앱에서는 요청 완료 시점에 로딩 상태를 종료한다.
- 반투명 탭바가 목록 위에 놓이므로 `LazyColumn` 하단 `contentPadding`에 탭바 높이와 시스템 안전 영역을 반영한다.
- 스켈레톤과 갱신 상태를 접근성 서비스에 알리고, 시각 효과만으로 상태를 전달하지 않는다.

API 참고: https://developer.android.com/develop/ui/compose/components/pull-to-refresh

## Codex에 전달할 작업 요청

> 첨부한 `pull-to-refresh-container-export.html`과 이 명세를 참고해 현재 프로젝트의 기존 목록 화면에 Ien 스타일 Pull to Refresh를 적용해 주세요. 먼저 기존 디자인 토큰, 반투명 탭바, 목록·스켈레톤 컴포넌트를 확인하고 재사용해 주세요. `PullToRefreshBox`의 `isRefreshing`, `onRefresh`, `state`, `indicator`를 실제 화면 상태에 연결하고, 첫 로딩과 기존 목록 갱신을 구분해 주세요. 상시 새로고침 안내나 별도 새로고침 버튼은 추가하지 마세요. 목록 하단 콘텐츠가 탭바에 가려지지 않게 해 주세요.
